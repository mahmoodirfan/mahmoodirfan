## Tools you can use

| Tool | Use it to | Start here |
| :--- | :--- | :--- |
| **RasterTrend** · QGIS | Explore monotonic trends and Sen's slope in raster time series. | [Code & guide](https://github.com/mahmoodirfan/RasterTrend) |
| **TrendShift** · QGIS | Locate the strongest abrupt shift in a raster time series using Pettitt's test. | [Code & guide](https://github.com/mahmoodirfan/TrendShift) |
| **OpenGeoEnrich** · QGIS | Add population, land-cover, terrain, road and facility indicators to vector features. | [Code & guide](https://github.com/mahmoodirfan/OpenGeoEnrich) |
| **spatialdrought** · Python | Calculate SPI, SPEI, VCI, TCI, VHI and CDI on gridded data. | [Code & examples](https://github.com/mahmoodirfan/spatialdrought) |

Each repository documents its inputs, workflow and limitations. Choose the tool that fits your question and start with a small study area.

## Where I work

- **Agriculture:** crop mapping, vegetation time series, harvest timing and weather index insurance.
- **Climate and ecosystems:** drought, rangeland condition, marine heatwaves and coastal environmental change.
- **Geospatial development:** QGIS Processing plugins, Python automation and Google Earth Engine workflows.

My core tools are **Python, Google Earth Engine, QGIS, ArcGIS Pro and R**, working with optical, SAR and gridded climate data.
